Shi Ming's Diary

Weekly reflections on building Limos.

Week 1

Objectives Achieved

  • Liaise with team members
  • Agreed on communication channels (Telegram, Discord)
  • Brief introduction on Discord
  • Role assignments and preliminary decisions
  • Appointed team leader
  • Discussed project scope
  • Studied market and competitors
  • Decided on what infrastructure to utilise
  • Identified rough scope of project
  • Shared Google Docs and file sharing on Discord
  • Wrote down findings mentioned previously into a digestible format

⚠ Challenges

Missing member in group.

💡 Reflection

This first week was mostly spent familiarising myself with what is expected of the project, defining preliminary requirements and expectations, and meeting with my groupmates. Teammates seem to be very capable and reasonable, and communication channels were set up without a hitch.

Week 2

Objectives Achieved

Created first draft of project proposal:

  • Executive Summary
  • Introduction
  • Project Description
  • Background
  • Objectives
  • Scope and Problems of Limitation
  • Development Method

⚠ Challenges

  • Unclear direction and feature feasibility.
  • Not clear on objectives.

💡 Reflection

Second week cleared with the first draft of the project proposal done. However, it was not very clear how to proceed as meetings for this week had not been released, and the expected "project website" was left somewhat ambiguous — a prototype, or a website to house a single source of truth. Hopefully the confusion can settle once the meeting with Mr Tian happens, after which we can proceed to create our user stories, use cases, instruction manual, and UML diagrams. Looking forward to maintaining the momentum we've held so far.

Week 3

Objectives Achieved

Created user stories, use case descriptions, BCE diagrams, and sequence diagrams.

⚠ Challenges

  • Unclear expectations for Submission 1, including which documents were required and some details of the objectives.
  • Changing requirements meant the diagrams needed frequent updates.

💡 Reflection

We need a clearer way to track what has been done, who did it, and what is still outstanding. A better system for tracking and collaborating on work is required, especially for documentation.

Week 4

Objectives Achieved

  • Prioritised designing and building the core application components before adding extra features.
  • Split design work among team members by application page and user role.

⚠ Challenges

  • Understanding how Firebase works and how to integrate it with Flutter.
  • Software updates left several accounts unusable.

💡 Reflection

We experienced significant feature creep as we spread our time too thinly. We should reduce the scope of implementation for physiotherapists and focus on perfecting the dietary aspects of the application.

Week 5

Objectives Achieved

  • Began connecting the Flutter application to Firebase.
  • Held the first meeting with the supervisor to review progress and agree on next steps.

⚠ Challenges

  • Unclear responsibilities and a lack of communication.
  • Time pressure before the review.

💡 Reflection

We should proactively ask about responsibilities and strive to keep everyone up to date on project news.

Week 6

Objectives Achieved

  • Continued developing features carried over from the previous week.
  • Began writing test cases for the application's features.

⚠ Challenges

  • Bug fixes and dependency issues.
  • Limited documentation made development on existing features difficult.

💡 Reflection

The team is communicating more, but the lack of earlier documentation is making development slightly difficult. The team is making good progress on development, thanks in large part to Marcela.

Week 7

Objectives Achieved

  • Continued writing and running test cases, recorded the results, and updated the application as needed.

⚠ Challenges

  • Implementation by different developers lacked documentation, making it difficult to work across features.

💡 Reflection

Marcela added test scripts that greatly improved development speed by allowing requirements to be tested automatically. Thanks to Marcela and Augustine!

Week 8

Objectives Achieved

  • Worked on the technical design manual.
  • Continued testing to make sure all features worked as expected.
  • Held a second meeting with the supervisor to review project progress.

⚠ Challenges

  • Frequent system design changes meant many diagrams also had to be updated, which took a lot of time.
  • Changes to the diagrams required a complete revamp of the underlying documentation.

💡 Reflection

We put off clarifying some areas that should have been settled earlier, causing avoidable complications. We need to ask for clarification sooner.

Week 9

Objectives Achieved

  • Continued testing to make sure all features worked as expected.
  • Started preparing presentation slides for the midpoint system demo.

⚠ Challenges

Keeping our effort consistent during a busy period, which was manageable with good time management.

💡 Reflection

Revisiting the documentation has revealed flaws and gaps that need to be filled. This provides a great springboard for the next cycle of development.
