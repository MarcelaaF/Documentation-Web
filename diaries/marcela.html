Marcela's Diary

Weekly reflections on building Limos.

Week 1

Objectives Achieved

  • Liaised with team members.
  • Agreed on communication channels (Telegram and Discord).
  • Brief introduction on Discord.
  • Role assignments and preliminary decisions.
  • Appointed a team leader.
  • Discussed the project scope.
  • Identified the target market and competitors.
  • Decided on the infrastructure to use.
  • Shared Google Docs through Telegram.
  • Listed the functional requirements for the application.
  • Documented all findings in a structured format.

⚠ Challenges

One team member was absent during the initial meeting, making it difficult to assign responsibilities.

💡 Reflection

During the first week, our team met through Discord to introduce ourselves and discuss the project expectations. We agreed on the application's features, functionalities, development tools, and software. Personally, many of these technologies are new to me, so I expect to spend additional time learning and becoming familiar with them.

Week 2

Objectives Achieved

Create project proposal that includes:

  • Executive Summary
  • Introduction
  • Project Description
  • Background
  • Objectives
  • Scope and Limitations
  • Development Methodology

Create project website that includes:

  • Created members' personal diary pages.
  • Prepared meeting minutes.
  • Developed the project timeline page.
  • Researched the technologies required for the project.
  • Installed the software and development tools needed.

⚠ Challenges

  • Still uncertain about the overall workflow for mobile application development.
  • The application's functionalities are still evolving and will become clearer after completing the prototype.

💡 Reflection

There is still some confusion while preparing the project proposal. Since many of the software tools are new to us, there is a steep learning curve. However, our team has been collaborating well by sharing ideas and helping each other whenever someone encounters difficulties.

Week 3

Objectives Achieved

Create project proposal that includes:

  • Create user stories
  • Splitting roles and responsibilities based on the user stories

Create diagrams for assigned user stories, which includes:

  • Use-case diagram
  • Use case description
  • BCE diagram
  • Sequence diagram
  • Update Taiga so that all the teams are aware of where the task is at

⚠ Challenges

Some of the application's workflows and sequence flows are still unclear, and certain aspects of the system design have not yet been finalized. We are continuing to discuss these areas as a team to ensure everyone has a clear understanding before moving forward with the implementation.

💡 Reflection

There is still a bit of miscommunication within the team but we manage to discuss and reach a better understanding. Everyone in the team is very dedicated to contributing their part in building the system which makes it easier to work together with. We are all aligned with the splitting of roles and responsibilities and everyone helps one another when there is an issue going on.

Week 4

Objectives Achieved

  • Start creating wireframe so we have a ground standing of what the application will look like as a team.
  • Splitting the responsibility on who will design which page/role of the app.
  • Focus on designing the core components and adding additional features.
  • Finalising the diagrams.
  • Start implementing the actual working app focusing on the core components first.

⚠ Challenges

Confused with the implementation of Firebase and how to connect Flutter to Firebase, but slowly we managed to build it as a team.

💡 Reflection

Communicate better with the team about which features or part of the app should be done or closely monitored first.

Week 5

Objectives Achieved

  • Started designing the wireframe of the app based on the user stories.
  • Started connecting Flutter with Firebase.
  • Implemented core functionalities, mainly focusing on the normal user's screen.
  • Continued debugging the code and fixing errors.
  • Set up Firebase rules for authentication and the Firestore database to store the user's data.

⚠ Challenges

There were some readjustments to the data workflow of the app, which meant we might need to update some of the diagrams based on the new workflow.

💡 Reflection

This week, we made good progress on the app by starting the wireframe design and connecting Flutter with Firebase. We were also able to implement the core functionalities for the normal user's screen. However, we had to make some adjustments to the data workflow, which may require us to update some of our diagrams in the following weeks.

Week 6

Objectives Achieved

  • Continued the work from Week 5.
  • Continued debugging errors for the normal user's screen.
  • Started designing the admin and business partner's wireframes.
  • Started implementing half of the core functionalities for the admin and business partner's screens.

⚠ Challenges

Similar to the previous week, there were some changes to the data workflow for the admin and business partner's screens, so we might need to update the diagrams based on the new data workflow of the app.

💡 Reflection

This week, we continued working on the normal user's screen while also starting the admin and business partner's screens. We focused on debugging the existing features and started designing the wireframes for the other roles. We also began implementing some of their core functionalities. However, the changes in the data workflow meant that some of our diagrams might need to be updated.

Week 7

Objectives Achieved

  • Focused on finalising the normal user's app.
  • Started adding advanced features into the user's screen.
  • Changed some of the app's functionalities to make it more user-friendly.
  • Continued debugging and testing the app to make sure the implemented features were working properly.

⚠ Challenges

No setbacks this week.

💡 Reflection

This week, we focused mainly on finalising the normal user's screen and adding some advanced features. We also made some changes to the app's functionalities to make it more user-friendly and easier to use. Overall, the progress this week went smoothly and we were able to complete the planned objectives without any major setbacks.
